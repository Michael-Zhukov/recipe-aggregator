\# Recipe Aggregator



Агрегатор рецептів з відкритих кулінарних API. Проєкт призначений для збору та подальшого аналізу інформації про рецепти, інгредієнти та час приготування.



\## Про проєкт



Предметна область проєкту — рецепти та кулінарні дані. Джерелом даних будуть відкриті кулінарні API, які надають інформацію про рецепти у структурованому форматі. Основне завдання — зібрати достатню кількість рецептів для подальшого аналізу. Планується досліджувати поширеність окремих інгредієнтів у рецептах. Також буде аналізуватися залежність та розподіл часу приготування різних страв. Отримані дані можна буде використовувати для статистичного аналізу та побудови висновків.


\## Git workflow

Проєкт розробляється з використанням окремих гілок для кожної задачі.


\## Нормалізація назв рецептів

Назви рецептів нормалізуються перед подальшою обробкою:
- видаляються зайві пробіли на початку та в кінці;
- кілька пробілів між словами замінюються одним;
- назва переводиться в нижній регістр.

Приклад:

`"  Chicken   Pasta  "` → `"chicken pasta"`
